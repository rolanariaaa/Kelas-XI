🆕 FITUR BARU YANG DITAMBAHKAN:
═══════════════════════════════════════════════════════════════

1. 📊 STATISTIK SEDEKAH
   → Total donasi, bulan ini, minggu ini, hari ini
   → Progress bars animated
   → Target bulanan
   → Kategori terbanyak
   
2. 🏆 PAPAN PERINGKAT (Leaderboard)
   → Top 10 donatur terbaik
   → Badge Gold/Silver/Bronze
   → Lihat posisi Anda
   → Total donasi & jumlah transaksi
   
3. 🔔 NOTIFIKASI
   → Update sedekah berhasil
   → Kampanye baru
   → Target tercapai
   → Naik level
   → Badge unread
   
4. ⚡ QUICK DONATE
   → Sedekah cepat dari home
   → FAB (kanan bawah)
   → Tanpa banyak klik
   
5. 🎖️ ACHIEVEMENT SYSTEM
   → Level: Pemula → Aktif → Dermawan → Master
   → Poin Pahala (1 poin = Rp 10.000)
   → Progress bar ke level berikutnya
   → Streak counter 🔥
   
6. 📍 MODERN NAVIGATION
   → AppBar dengan gradient
   → Collapsing toolbar
   → Smooth scrolling
   → Profile & notif button
